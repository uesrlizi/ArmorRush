# 音效台账

- 管线：`tools/gen_sfx.py`（实录转换 + 定向合成垫；依赖 `pip install soundfile numpy`）
- 素材：`tools/ref_sfx/`（CC0：Kenney Impact Sounds 全量 130 ogg + qubodup 挥风 10 flac，LICENSE 在目录内）
- 播放：`scripts/sfx.gd`（autoload `Sfx`，固定 12 声道池，全非定位）
- 产物：`assets/sfx/*.wav`（16-bit PCM / 44100 Hz / 单声道）

## 设计规约

- **实录为底（实装教训，别回退）**：第一版全合成被判"差劲、出戏、一点都不真"——
  纯合成模拟物理声（枪/金属/挥砍/脚步）没有物理源的调制组织，耳朵一听就假。
  现在实录给"源质感"（瞬态/共鸣体），合成只保留两类被认可的性质：
  纯噪声能量（爆炸/循环床/尘尾，无音高性）与电子源（UI sting、FCS tick）。
  合成低频 thump 只做"质量垫"叠在实录上（参考工程 collapse 配方验证的结构）。
- **全非定位，"镜头即耳朵"**：侧视跟焦，战斗事件永远在画面内，位置不参与混音；
  Comms 语音走它自己的 Radio 总线，互不掺和。
- **选型依据**：`tools/profile_refs.py` 输出素材画像（时长/谱质心/RMS），
  按画像匹配用途性格（挥砍要亮、钝击要暗、脚步居中）。变体 = 换源或变调重采。
- **响度档位纪律**（全库平衡拧总线推子，别散改逐键 dB）：
  命中确认（近战命中/受击/爆炸）> 出手（枪/斩）> 移动（跳/落地/脚步）> 环境。
  最高档给近战命中 -4 与玩家被毁 -2：前者是保命反馈，后者是终局。
- **克制规约**："不是每个事件都该有声音"——起跳无音（用户定论：移动系声音宁缺毋滥）、
  前摇只给 -15 的轻上膛咔、连段衔接不配音、打墙声 -14 且 80ms 节流、
  触控按钮不配点击音（有按压视觉+震动，声音是多余的第三层）。
- **一个事件原则**：同拍不叠多层——近战命中只发一声 melee_hit（顿帧+震屏+手柄已在同一拍）。

## 总线

```
Master
├── Sfx   （战斗/移动/UI 音效，运行时建）
├── Amb   （环境床循环，-18dB，运行时建）
└── Radio （Comms 语音 + squelch，320–3200Hz 带通，comms.gd 建）
```

## 循环音的接缝纪律（gen_sfx.py 侧）

踩过的坑，重写循环音生成前先读：

1. **延长段交叉替换头部**（不是"尾部卷进头部"）：头部 fade 帧从"延续尾部状态的
   延长段"渐变回原信号，循环点落在原始信号自然连续处（x[N-1]→x[N]）。
2. **周期成分先闭合**：谐波频率 snap 到循环长的整数分频（52.5=84×1/1.6），
   LFO/颤音取整数周期，否则交叉淡化救不了相位跳变。
3. **母带 IIR 冷启动**：HP38 的高通状态从 0 起步会把头部第一样本的低频分量压没
   （首样本输出≈0.5%·s₀），循环点跳变可到正常步进的 8 倍以上。解法是滤波状态
   绕环 3 圈收敛：信号拼 3 份过滤取中段（`master(x, loop=True)`）。
4. 自验口径：接缝跳变应落在全曲差分分布的 p99 以内（`bisect` 分位检验），
   单看"接缝/平均步进"的倍数会误伤波峰处的正常大斜率。
5. **循环床禁用正弦 LFO 调幅**：1~3Hz 的正弦包络（哪怕深度只有 ±20%）会被听成
   规则脉动，循环音"一段一段"（slide_loop 踩过，拍频+基频全是可闻周期）。
   要起伏就用非周期的慢随机漂移（强低通布朗噪声做调制源）。自检口径：包络
   （去滑动均值）在 0.5~4Hz 的谱应为连续谱——最大谱线/中位 < 6，离散线谱即 FAIL。
