## 总览

一局 = 4 个普通关（洗牌袋抽）→ 第 5 关 = RUSH 终局（本局未抽到的 3 台 BOSS 连战）→ 结算。通关即结束，无无尽。死亡=新一局。

肉鸽循环两半对跑：**玩家能力在长**（BOSS 概率爆装备）× **世界压力在长**（疾驰倍率）。倍率是难度侧负反馈、不是玩家成长（定位修正）。

设计公理：不加按键、不加菜单；战斗内零文字（视觉即公告）；随机发生在开局前与击杀点，不碰操作与节奏。

## 2. 疾驰倍率 ✅ 2026-11-08 实装（同日用户调向：输出涨/删流失/跨关保持）

- ×1~×5；**按对敌输出涨**（防御后实际伤害，BOSS 战 400 实伤=+4 档锚点）+击杀收头；受击**按伤害量扣**（不按发数，=唯一掉档来源）；**无停手流失**——打完没怪可打的跑图期不该罚（BOSS 战死水问题=输出渠道解决）。
- 倍率档 = 刷怪密度档（SPAWN_ENEMY_GAP 乘区）：打得越好怪越凶；受击掉档 = 被围自动退出高密度，自我纠正；新手低档 = 天然难度保护。
- 计分唯一公式 = 击杀分 × 当时倍率；评级/反制/用时只展示。
- BOSS 触发按**基础分**（BOSS_SCORE_TRIGGER 不乘倍率），否则高倍率吞掉自己的收益。
- 全系统唯一自动平衡器：装备→杀得快→倍率涨→密度涨，成长自动转压力。平衡器不许有第二个（阶梯因此不碰刷怪流）。
- 实装落点：开关与数字全在 `balance_global.gd`「疾驰倍率」段——`MULT_ENABLED` 总开关（false=旧制）+ `MULT_STEP`(20)/`DAMAGE_FACTOR`(0.2)/`KILL_FACTOR`(0.6)/`HIT_FACTOR`(10)/`GAP_STEP`(0.8)（全待调参）；状态正本=`RunState.mult_*`（`mult_max_run`/`hits_taken` 局级累计进结算）。
- **进度跨关保持**（2026-11-08 用户拍板）：不清档带进下一关——高手带高密度开局、吃伤带低档喘息，「带着战果/伤痕进下一关」的局内叙事；只 `start_run`（新一局）归零。
- 计分用**涨前档**（先按当前倍率结账，涨档从下一次击杀生效）。
- 涨进度=输出+击杀收头两路（伤害走 `Enemy.take_damage` 防御后实伤结算处；**失衡不独立涨**——失衡期受伤 ×1.5 加深自动多打输出=打失衡的奖励由输出渠道间接兑现）；「反制」随擦弹砍掉降级为结算展示（§5），暂无事件源，后置。
- 密度乘区只乘杂兵间距（`Spawner._roll` × `RunState.mult_density_factor()`），障碍间距不归倍率（跑酷节奏不动）。
- 展示：HUD 顶栏右上得分线下「倍率 ×N」读数（得分与倍率同侧挨着读，2026-11-08 用户定；用时+关卡在左上；涨档闪一下提注意，掉档=负反馈安静回落，落地静默显示携带档）；结算进组=受击数+最高倍率两组（倍率关不建；反制数/拾取清单仍待后续）。
- dev 冻结闸 `RunState.mult_frozen`：autotest 与 transition_probe 置真——前者保刷怪节奏确定性，后者因跨关保持后「每关得分=BOSS_SCORE×关序」不再成立、冻结回旧公式账（倍率公式归 probe_run_loop G 段纯逻辑验）。

## 3. 难度阶梯（收窄：只管 BOSS）✅ 2026-11-08 实装（同日用户补体量增长）

- 关序只管 BOSS：出招密度（后摇 ×0.95^(n−1) **下限 0.9**、弹数第 4 关 +1）+ **体量增长（2026-11-08 用户修正）**：BOSS 血量与失衡阈值 ×1.12^(n−1) **封顶 ×1.4**（1.3~1.5 取中）。原「血量一律不加」红线就此对 BOSS 废止（难度梯度不只节奏，体量也涨）；**杂兵/精英血量与失衡账仍一律不加**。
- RUSH 折扣叠加在其后：封顶档 1.4 × RUSH 0.7 ≈ 0.98 ≈ 原血量——RUSH BOSS 手感≈普通关 BOSS（血条比例/二阶段阈值走 hp_ratio，不提前）。
- 杂兵/精英密度归倍率；阶梯不压刷怪流（两旋钮拧一条流会互相污染因果）。
- RUSH 凶度封顶第 4 关档。
- 实装落点：常量=`balance_global.gd`「难度阶梯」段（`LADDER_ENABLED` / `RECOVER_MULT` 0.95 / `RECOVER_MIN` 0.9 / `EXTRA_BULLET_STAGE` 4 / `GROWTH_MULT` 1.12 / `GROWTH_MAX` 1.4）；换算三方法在 `RunState`（`ladder_recover_factor()` / `ladder_bullets_extra()` / `ladder_growth_factor()`，Balance 保持纯常量）。
- 后摇收口=两处：`boss.gd` 与 `pursuit_boss.gd` 各自的 `_enter_recover`（saltmill 覆写走 `super` 同被覆盖）——全部招后摇乘系数，二阶段缩短系数叠加其上。下限 0.9 的实账：封顶档实际生效（0.95³=0.857 被接住=出招密度最高 +11%，2026-11-08 用户定「略高压回」）。
- 弹数 +1 接在齐射计数读取位（ch1 弹雨 / ch2 熔渣 / ch3 弹雨+浮雷 / ch4 光球+潮+爆闪 / ch5 空爆 / ch6 装药+抛石 / ch7 跳弹+深弹装药 / ch8 泉幕[统一 `_geyser_count()` 取数，几何/时序同一把尺]+灼烤）；直射持续流（扫射时长定义）不适用=弹数没得加。
- 体量增长闸门=`Enemy._ladder_scaling()` 虚方法（默认 false，Boss/PursuitBoss 覆写 true——与 `_rush_discount()` 同款模式）；血量乘在 `Enemy._max_hp()` 唯一缩放入口、失衡阈值乘在两线各自的 `_impact_resistance()` 覆写（杂兵 40/精英 40 两刀必失衡账不动）。
- RUSH 封顶不读 `rush_active`：stage=5 被 `mini(stage, RUN_NORMAL_LEVELS)` 自然封到第 4 关档（效果等价且更简）；旧制无限滚动同封=凶度有顶。

## 4. 轻肉鸽：BOSS 概率爆装备 ✅ 实装（用户拍板 6 槽 15 成员，2026-11-08 同日多轮收敛）

- 掉落源 = BOSS 击杀（普通 4 + RUSH 3），爆率 50%。期望 = 源数×爆率：2.0 + 1.5 ≈ 3。
- **槽位 6，同槽位不爆**：掉落时从「未持有槽」里掷；已持槽划出掉落表。
- 为什么 6 槽不是 3 族：3 族下期望 3 掉落 = 每局装满（趋同回归）；6 槽下手持 2~3 枚，机体永远没装满——终局差异大，且「装不满」本身就是每局的性格。
- 槽位上限 = 可辨通道数：加槽先加通道，数值-only 槽违背具象化。
- 全员小正值（随机不可选 = 没同意吃负面）；无纯外观位；同槽成员等强。
- **成员命名=零件名词**（用户定，多轮收敛）：名字要像一件装备的名词，不是招式/形容词（速射/迅斩/回燃这类不成立）；长短按需不硬凑四字（两字成立的保留，同 BOSS 名「哨兵」），也可以是 AC 式干说明（如「反应装甲」）；**名字要能连到成员的视觉通道**——推进槽整组按推进剂种类起名，焰色即身份证（青焰=液氢 / 白蓝焰=甲烷罐 / 紫焰=离子喷口）。现役：弹链/穿甲弹/双联装、重刃/三连刃/薄刃、液氢/甲烷罐/离子喷口、复合装甲/反应装甲、壁垒/复层盾、蜂巢/磁轨炮。成员名=拾取播报行与结算清单共用（`label`，id 不随 label 动）。
- 拾取：BOSS 终爆那一拍芯片从爆点弹出（装备从终爆里炸出来），朝玩家定速斜抛，后半程渐混吸附到身上——**实际必捡**（别让躲弹跳跃漏掉掉落 = 两次随机叠加难受），玩家跑动也照收；往前跑迎上去收得更快。
- 掉落物 = **装备芯片**：对角双切深色方牌 + 槽位图标（**形状=哪类零件**，每槽一枚）× 成员色（**颜色=哪个成员**，芯片边与图标同色，**颜色即预告**：飞来青色喷口牌 = 液氢）；全程直立不翻滚（图标要可读）。返工起因：首版「通用小件×成员色」在画面上只是一根色条——同槽三个枪成员全是黄色族，颜色根本分不出是啥。
- 生效瞬间 = 物品音 + 通道当场换色/换形 + **拾取播报**：同一枚图标从机体飞到 HUD 左上拾取栏队尾（先升后横弧线 0.5s，落位回弹一拍），栏下滑出「成员名 效果」一行（如「液氢 推进回气加快」，停 2.6s 淡出）；不弹窗、不压画面中央、不在机体头顶飘字（跳字破坏平涂，见 §5 擦弹）。结算回执照旧记清单。
- **拾取栏**（HUD 左上「关卡」下）：开局是空的，**捡到一个加一枚**成员色图标（不画空槽位）；新关落地按持有表重摆（装备跨关携带）。图标压同形黑影硬投影（浅色成员在亮天章被天色吃掉）。回答「装到身上看不出来」。
- 时序：BOSS 死后有掉落时黑场延迟 1.7s→`LOOT_CLEAR_DELAY` 5.0s（终爆 ~0.9s 播完 + 斜抛吸附 1.15~1.85s 到手 + 播报行滑入 0.35s + 停 2.6s + 余量；用户反馈「显示文字之后太快到下一关」）；无掉落照旧 1.7s。
- RUSH 照掉（能力曲线冲过终点线）。
- 实装落点：槽位/成员正本=`scripts/core/balance/balance_mods.gd`（`SLOTS` 6 槽 + `MEMBERS` 15 成员，加槽/加成员=只加数据）；开关与数字=`balance_global.gd`「轻肉鸽装备」段（`LOOT_ENABLED` + `LOOT_DROP_CHANCE` + 斜抛/吸附参数 `LOOT_FLIGHT_*`/`LOOT_SHOT_*`/`LOOT_HOME_*` + `LOOT_CLEAR_DELAY` + `LOOT_ICON_SHADOW_ALPHA`）；状态与掷骰=`RunState.mods_*`（`mods` 持有表 start_run 清空、`mod_member()`/`mod_stat()` 统一访问器、`roll_drop()`=爆率×未持有槽、`handover_shield` RUSH 携带）；掉落件=`scripts/world/loot_pickup.gd`（斜抛→渐混吸附→授予一条连续弧不落地，入组 `loot_pickups`）；生成接线=`main.gd _on_boss_defeated`：击杀瞬掷定、`BOSS_DEATH_FINALE_TIME` 终爆那一拍 `spawn_loot_drop` 生成（装备从终爆里炸出来），转场计时器回调先 `LootPickup.collect_in_flight()` 兜底（在途件就地授予=一次都不许丢）。

## 5. 否决 / 搁置记录（防止绕回来）

- **三选一卡**：打断前进 + 没构筑的选择没意义。
