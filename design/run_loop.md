> 2026-11-04 讨论定案。数字全部待调参；正本随讨论推进更新。
> **§1 已实施（2026-11-05）**，开关组在 `balance_global.gd`「局内循环 v2」段：
> 总开关 `RUN_LOOP_ENABLED`（false=整套退回旧制无限滚动关）+ 细则开关
> `RUSH_NO_MOBS` / `RUSH_HP_DISCOUNT_ON`+`RUSH_HP_DISCOUNT` / `RUSH_NO_HEAL`；
> 关数=`RUN_NORMAL_LEVELS`（4），阵容台数=`RUN_RUSH_COUNT`（3）。

## 总览

一局 = 4 个普通关（洗牌袋抽）→ 第 5 关 = RUSH 终局（本局未抽到的 3 台 BOSS 连战）→ 结算。通关即结束，无无尽。死亡=新一局。

肉鸽循环两半对跑：**玩家能力在长**（BOSS 概率爆装备）× **世界压力在长**（疾驰倍率）。倍率是难度侧负反馈、不是玩家成长（定位修正）。

设计公理：不加按键、不加菜单；战斗内零文字（视觉即公告）；随机发生在开局前与击杀点，不碰操作与节奏。

## 1. 固定 5 关 + RUSH + 结算 ✅ 2026-11-05 实装

- 洗牌袋照抽 4 关；剩余 3 个场景 = 第 5 关 RUSH 阵容（7 场景池时每局恰好看满 7 台；池变大后从没抽到的里随机挑 3 台）。
- RUSH = 逐台**跳场景**，不把 BOSS 搬进一张图（深弹要落海、涌浪要漫桥、章专属弹只按本章天色调色）。
- RUSH 细则：无杂兵；凶度停在第 4 关档（**暂无着落点：难度阶梯 §3 未实装，现无按关序的缩放可封顶；§3 落地时读 `RunState.rush_active` 封档**）；未经过精英预教的 BOSS 血量打折（二阶段=加量不加招，一阶段本身在教招）→ 实装为 RUSH BOSS 一律 ×`RUSH_HP_DISCOUNT`（`Enemy._max_hp()` 缩放唯一入口，血条比例/二阶段阈值不提前）；击破间不回血，难度全部来自连战（实装=血量跨场景携带 `RunState.handover_hp`，满血只给到进 RUSH 为止）。
- 关数 5 与爆率同进 Balance 常量；局长用用时 HUD 实测后校准（死亡代价=局长，>10min 会疼）。
- 结算页只展示不加分：得分 / 第 N 关·用时 / 受击数 / 反制数 / 最高倍率 / 本局拾取清单（**本期只接了得分/关卡/用时三组；通关标题「作战完成」吃本章墨色，不拍 gameover 音**；后四项随 §2/§4 进组）。
- RUSH 落地即战：BOSS 进场不等击杀分（`Spawner.start()` 分叉）；三台共用关号 5。
- 进度显示（2026-11-06）：顶栏与结算同一出处 `RunState.progress_parts()`——普通关「关卡 4/5」（带分母=看得见终点），RUSH「最终战 1/3」（第几台/阵容台数，通关结算报「最终战 3/3」）；旧制照旧「关卡 N」。
- 结算重开闸（2026-11-06，防误触）：入场动画（0.86s）播完才受理重开，重开提示与开闸同拍亮起（看见提示=能按）；通关再多锁 1s（`CLEAR_RESTART_LOCK`，阵亡 `RESULT_RESTART_LOCK`=0）；战斗结束即断开按住的操作（`RESULT_CUT_HELD_INPUT`，须松手重按才算）。总开关 `RESULT_RESTART_AFTER_INTRO`=false 回旧制（面板一出即开闸）。

## 2. 疾驰倍率

- ×1~×5；击杀/反制/打出失衡上涨，受击**按伤害量**扣进度（不按发数），停手缓慢流失，BOSS 战暂停流失。
- 倍率档 = 刷怪密度档（SPAWN_ENEMY_GAP 乘区）：打得越好怪越凶；受击掉档 = 被围自动退出高密度，自我纠正；新手低档 = 天然难度保护。
- 计分唯一公式 = 击杀分 × 当时倍率；评级/反制/用时只展示。
- BOSS 触发按**基础分**（BOSS_SCORE_TRIGGER=100 不乘倍率），否则高倍率吞掉自己的收益。
- 全系统唯一自动平衡器：装备→杀得快→倍率涨→密度涨，成长自动转压力。平衡器不许有第二个（阶梯因此不碰刷怪流）。

## 3. 难度阶梯（收窄：只管 BOSS）

- 关序只管 BOSS 出招密度：后摇 ×0.95^(n−1) 下限 0.7、弹数第 4 关 +1（数字待调）。
- 血量一律不加（拉长战斗=拉长局长=加重死亡代价）。
- 杂兵/精英密度归倍率；阶梯不压刷怪流（两旋钮拧一条流会互相污染因果）。
- 全系统难度原则：**难度只走威胁密度，不走血量**。
- RUSH 凶度封顶第 4 关档。

## 4. 轻肉鸽：BOSS 概率爆装备

- 掉落源 = BOSS 击杀（普通 4 + RUSH 3），爆率 50%。期望 = 源数×爆率：2.0 + 1.5 ≈ 3。
- **槽位 7+，同槽位不爆**：掉落时从「未持有槽」里掷；已持槽划出掉落表。
- 为什么 7 槽不是 3 族：3 族下期望 3 掉落 = 每局装满（趋同回归）；7 槽下手持 2~3 / 7，机体永远没装满——终局差异大，且「装不满」本身就是每局的性格。
- 槽位上限 = 可辨通道数：加槽先加通道，数值-only 槽违背具象化。
- 全员小正值（随机不可选 = 没同意吃负面）；无纯外观位；同槽成员等强。
- 拾取：掉在击杀点地面 + 磁吸半径放大到**实际必捡**（别让躲弹跳跃漏掉掉落 = 两次随机叠加难受）；跑过去捡 = 疾驰被奖励。
- 掉落物 = 通用小件一件 × 成员色 tint，**颜色即预告**（弹出青色件 = 青焰，一秒后才到手）。
- 生效瞬间 = 物品音 + 通道当场换色/换形；战斗内零文字；结算回执记清单。
- RUSH 照掉（能力曲线冲过终点线）。

### 槽位 × 通道盘点

| 槽位 | 表现通道 | 现成 | 成员原型（数值全待调） |
|---|---|---|---|
| 枪（机炮） | 曳光亮/粗/道数，**色相留黄色族**（敌我共弹语言不重开） | ✓ | 白热=射速 0.22→0.18 / 穿甲=冲击+3、击退+40% / 双曳光=双发 3×3 |
| 刀 | 刃光整套转色+形，保一段≠二段色差 | ✓ | 绯红=近战+4/+6 / 鎏金=连段窗+0.25s、二段后摇−0.1 / 疾影=前·后摇−20%（突进速度不动） |
| 背部推进 | 主焰色（只碰回气侧，不动推力/上升上限） | ✓ | 青焰=回充+25% / 重氢白焰=容量+0.3s（黄线小步） |
| 腿部推进器 | 姿控焰色/长度（与主焰是两套焰件，可分开 tint） | ✓ | 紫焰=空中回气延迟 0.30→0.15（第二名成员待补） |

## 5. 否决 / 搁置记录（防止绕回来）

- **三选一卡**：打断前进 + 没构筑的选择没意义。
- **擦弹**：反馈两头堵（跳字破坏平涂 / 静默=没做）+ 激励与反制几何打架（果断离开 vs 贴边蹭）+ 与倍率抢生态位。反制数进结算展示。
- **缴获（1 槽顶替）**：收集趋同 + 槽 UI 物理不存在。残留形态 = 肩部武器槽。
- **出厂型**（开局随机机型一局一定）：没组合没成长感——肉鸽要的是随战斗看到自己能力变化。
- **3 族 × 同族顶替**：抽 8 穿 3 = 终局趋同；顶替 = 换装打断节奏；且 3 族期望 3 掉落 = 每局装满。
- **今日航线**：要模式选择（违背打开就玩）或取代随机局。
- **第二机体**：碰机动几何。通关解锁涂装：往后放。
- **通关后无尽**：阶梯到顶 + 冲分终点已定，没意思。
