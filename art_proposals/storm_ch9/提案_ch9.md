# 场景提案 · 第九章「雷暴线场」（world_9）

## 1. 三层背景分工

**far 远景条（视差 0.9）：成片的主体块**
- 两排远山用整数周期的正弦折线画（每 1024 两周期，接缝两侧取值相同，平铺不断），后排青灰、前排深一档。
- 门型输电铁塔成排排在远山前面，塔间挂着垂弧导线，导线两端都接在横担的绝缘子串上。塔群就是本章的成片主体块（塔顶落在世界 310..360，远山脊顶 380..440）。
- 地平线一带铺雷光紫辉，用径向软光晕画；高空雷暴云只画成低对比的横条。条带里不画闪电或任何唯一地标。
- 底雾只压在脚下，不超过 100px。

**mid 中景条（视差 0.55）：挂件，四段构图各不相同**
1. 断头高架墩：本章最高的中景件，桥板顶在世界约 390，桥板断口露出钢筋。
2. 变压器台小屋，旁边立电杆，杆上挂变压器罐和航标紫灯。
3. 铁塔基座上剩半截残塔，带 X 形斜撑，顶端是断口。
4. 警示牌（牌面有亮缘描边，雷光紫警示杠）加一排栅栏桩。
- 每一段之间用断缆垂弧连起来，两端都接在实物上；落地碎缆两端都入地。
- 所有落地件的脚都在画布 488..500，在合成图上逐件压在 664 红线上，没有悬空（见图②）。

**地形性格：焦紫灰硬质荒原（地块 v2 @ `THEMES.p9_storm`）**
- 走道带：钢青色缆槽盖板（带端缝）、雷光紫电蚀焦痕（短线贴着带走，收敛）、砾石点。
- 立面：断面露头铁件（锚栓、断缆头），偶尔有埋缆警示紫杠渗出来。
- 墙脚：碎砾石堆。
- 档位节奏：按标准山体读法，两侧低平地留给高架墩和警示桩；中段高台放小屋和电杆，过渡台放塔基残段和倒伏巨塔。整条地形读作「沿线路检修道」：低平地是线路通道，高台是变电台地。

## 3. 章信号色

**雷光紫 `#a678e8`**：用在电蚀焦痕、航标灯、警示杠、BOSS 舷侧航标和举升辉光。它和独眼红 `#ff4640`、共享黄弹 `#ffee58` 三者色相互相错开。

## 4. 敌营配色（焦铁墨紫族，近黑=敌，不反转）

| 阶 | hex |
| --- | --- |
| LIGHT | `#5a5068` |
| BODY | `#3a3346` |
| BELLY | `#262032` |
| GAP | `#191524` |
| 独眼 | `#ff4640` |
| 点缀 | 雷光紫 `#a678e8`（BOSS 航标、举升辉光） |

- 本章是中调背景，不属于暗场章，所以按「近黑=敌」处理，不反转。敌营不用奶油白，也不用低对比浅色。
- 在青灰绿天上读作暗紫剪影（见图③）。墨紫敌营、焦紫灰走道带、青灰远山三者明度和色相都分开。走道带和敌营同属紫族，但敌营 BODY 比走道带暗一档以上，单位踩在带上靠明度分开；BOSS 悬在青灰天里，靠色相分开。
- HUD 用深字（天色中调偏暗，HUD 字色实装时以实机截图为准）。

## 5. 独层大件：倒伏门型巨塔（`env_storm_pylon`，独层宽 tile，同屏一份）

- 一座比远层塔群大得多的门型塔，被雷击后拦腰倒伏，主桁梁斜卧在荒原上。塔根坐地，塔头的断口挑在半空，悬垂绝缘子串的末端拖着一截坠缆落到地面（线段两端都落地或接实物）。塔身上还有一盏航标紫灯在闪。
- 尺度：必须明显大于远层塔，才读得出「巨」。主视景里倒伏塔的桁格尺度约是远层塔的 3 倍。
- 塔头断口这一侧要做成本章的辨识轮廓（斜指天空的长桁梁）。
- 落位照独层规矩：tile 宽大于 2400，tex_x 放在防回绕安全带内，画在不透明远条之后、MidStrip 之前；条带里不再放第二个大件。

## 6. 本章普攻换形方向

**方向：「断缆甩弧」**。BOSS 普攻不用机枪短梭，改成臂端绝缘子串蓄一次能，朝玩家出手瞬间所在的方向甩出一段沿缆走的弧光。弧光是看得见、走得慢的一次性实体，出手时锁定方向，之后不跟踪。

**和主题相配的理由**：
- 本章的视觉母题是「电沿着线走」，普攻就是把这条线甩出来，枪口真实存在：绝缘子串就是放电端，符合真实枪口律。
- 它属于 ch2 排炮重弹、ch4 钓灯爆闪、ch6 斗轮抛石、ch8 融盐重弹「出手锁定的一次性形态」这一家族，但形态不同于前四家（慢重弹、径向齐放、抛体落点、单发点放）。弧光是一段有长度、贴着导线读法的实体，玩家解法是「读弧线走向换层或挪位」。
- 可读性：弧光用雷光紫白热芯，在青灰绿中调天上读得出。快弹的读法是拉长度，这条规约正好让「一段弧」本身就成立。
