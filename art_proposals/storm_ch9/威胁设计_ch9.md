# 第九章「雷暴线场」威胁设计：精英「架线」与 BOSS「引雷」

本章的能力母题是**电沿着线走**。线是静止的，电从一端走到另一端，走到头才带电。玩家每一招都要先读两件事：线挂在多高，电走到哪了。

- 精英「架线」放线车：每次射出一对跨缆桩，桩高高/低交替，用来预教本章核心件「跨缆」——**高缆=贴地钻过去别跳，低缆=按住推进飞越或刹停等熄**。
- BOSS「引雷」浮空巡线舰：技能 A「跨缆网」（跨缆 p2 先高后低两段）和技能 B「引雷针链」（**罚跳**——贴地刹进缝或停在针列前，跳就挨弧）轮换，中间穿插普攻「断缆甩弧」。

数值全部只进 `scripts/core/balance/balance_world_9.gd` 的 const，命名按机体（`ELITE_STRINGER_*` / `CONDUCTOR_*` / `LIVE_SPAN_*` / `ROD_*` / `ARC_LASH_*`），不用章号（worlds.md §4b 门检 5）。

## §0 全章参照系约定（一切坐标只记这一本账）

**唯一口径：terrain.gd 碰撞口径。** 世界坐标 y 轴朝下。

1. **地表 g**：每个地块 `chunk.position = (i*320, top)`，`top = 664 − 64*tier`，tier 取 0/1/2，所以 g ∈ {664, 600, 536}（`scripts/world/terrain.gd:79-84`、`:218-219`；`scripts/core/balance/balance_global.gd:127-130`）。碰撞矩形的局部区间是 y∈[0, FILL_DEPTH]（shape 中心 (w/2, FILL/2)，`terrain.gd:86-90`），因此**碰撞顶就是局部 y0=0，等于世界 y=top**。运行时一律用 `terrain.surface_y_at(x)`（`terrain.gd:298-302`）取 g。下文所有「高度 h」都指 `h = g − y_world`，向上为正。
2. **可见层贴图（SVG 画布系）换算**：
   - 走道带 band 贴图：Sprite `centered=false`，位置为块内 (0,0)，region 320×66（`terrain.gd:223-230`，`BAND_HEIGHT=66` 在 `:33`）。换算式：**世界 y = top + canvas_y**。走道带 SVG 的可走可见顶线必须画在 canvas_y=0，不允许把「钢轨/盖板可见线」画在 canvas_y>0 再让单位去对它。
   - fill/桥件：画布从块内 y=66 往下排（`terrain.gd:240`），在碰撞顶之下，不参与任何站线。
   - far/mid 背景条：只是视差装饰，**不参与任何威胁锚点**。落地件按提案挂载账压在 664 线上（提案 §1，画布 488..500 落在 664），这只是观感，与判定无关。
   - 本章危险件贴图（桩、针、缆、弧弹）：每张 SVG 头注释写明**锚点画布坐标 (ax, ay)**。节点局部坐标 = (canvas − anchor) × scale。桩和针的锚点一律是**底部接地点**，节点 origin 也是接地点。
3. **单位挂点（世界系）换算**：
   - 玩家 origin 就是碰撞矩形中心，矩形 40×60 无偏移（`scenes/player/player.tscn:22-23`、`:160-162`；`balance_enemy.gd:34`「玩家碰撞中心离地 30」）。站立时 **中心 y = g−30，头顶 y = g−60，脚底 y = g**，判定盒半宽 20。（老记忆里「t2 站立头顶 470」=536−66，比 tscn 推出的 476 高 6px。本章所有余量都按 ≥10px 留，6px 出入不影响结论；探针按 tscn 口径断言。）
   - 危险件节点：桩和针的 origin 钉在 `(x, surface_y_at(x))`，落地即静止，零地形跟随。缆和弧线的端点取**桩顶/针顶的世界坐标**，即 origin + (0, −H)。
4. **BOSS 挂点以 `art_proposals/storm_ch9/bake_storm_units.py` 头注锚点为唯一准**（Visuals 局部系，取用一律 `global_position`，不另记手抄世界坐标）。换算：BOSS origin 悬浮于世界 y=370（hover 档），机体 300×180 原点画布 (150,90)。
   - **Muzzle = 前臂放电球，世界 y = 306**：ArmPivot 局部 (0,−64)（画布 (150,26)），放电球在臂局部 (−68,0)（臂画布 (10,22)，臂 96×44 枢端 (78,22)）→ Muzzle 世界 y = 370 − 64 = 306，世界 x = BOSS 原点 −68。悬浮位姿下普攻与主弧出膛高度 306。
   - **BayPort = 腹舱双桩口**，局部 (0,78)（画布 (150,168)）。
   - **RodPorts 背部三孔**，局部 (56,−38)/(80,−34)/(104,−30)。
   - 悬浮基准 hover 370、机体 300×180、船底 460、对最高台阶 536 净空 76 ≥ 70（worlds.md §4b 门检 2）。
5. **玩家运动账**（`scripts/core/balance/balance_player.gd:6-10`、`:75-79`；接线见 `scripts/*/player.gd:209-221`）：跑速 600、加减速 1800、起跳初速 −450、上升重力 1200、下落重力 800；空中按住跳跃会推进：向 −320 收敛，加速度 1000，槽 2.5s。**红线：跳跃初速和推进最大上升速度一律不动**，本章只算账不改。由此推出的常用数：

## §1 本章核心危险件「跨缆」LiveSpan（新弹种）

**构成**：两根跨缆桩（静止落点件，DrillCharge/ArcFence 同族）加一根挂在两桩顶之间的直缆。缆是静止线段，不跟随地形，不移动。

**两种桩型，读法只看桩高**：

| 型 | 桩高 H（缆高） | 判定带（缆 ±8） | 站立头顶 | 结论 |
| --- | --- | --- | --- | --- |
| 高缆（高桩，桩顶有双绝缘子盘） | 110 | h∈[102, 118] | h=60，余量 42 | 贴地跑过去安全；纯跳在 0.109 s 时头顶升过 h=102，被打 |
| 低缆（矮桩，桩身短粗） | 40 | h∈[32, 48] | 身体 h∈[0, 60] 跨过该带 | 站着必被打。**有效横宽 376**（320+2×(20+8)，R8），纯跳 h≥48 窗只有 329 px，**差 47 px，跳不过去**；按住推进 0.13 s 后 h≥48，能飞过去 |

**时序**（「电沿线走」的预警读法；一套全寿命 = 0.7+0.3+0.6+1.0 = **2.6 s**）：
1. 发射：Muzzle 上的 ThreatFlash 先驻留 0.6 s（直瞄无预判，按惯例给 0.6 s）。随后两桩用 MORTAR_GRAVITY 弹道解算、梯次 0.1 s 出膛，飞行 0.7 s。两桩之间拖一根松弛灰缆（Line2D 两端绑两个桩体，连接是真实的）。桩在飞行中就是最终形状，高矮一出膛就能读。
2. 落地：桩钉住竖立，灰缆收紧成直线，进入 idle 0.3 s，**无伤**。
3. 爬电 0.6 s（第二段预警，**无伤**）：一颗电花从 A 桩顶沿缆爬到 B 桩顶。电花爬到头，整根缆就带电。
4. 带电 1.0 s：伤害 10。玩家触一次缆，整套溃散（ArcFence「触幕即溃」同规），否则寿命到点直接熄灭。

**跨距、落位与平移（R6）**：
- 跨距 320，`x1 = px − 160 + clamp(vx·1.5, −400, 900)`，跨缆为 [x1, x1+320]。站着不动的玩家正好落在缆中心；满速跑的玩家在带电时刻正好在缆下（算式见 §2）。
- **有效横宽 376（R8）**：320 + 2×(玩家半宽 20 + 判定半厚 8)。后文所有出缆/换层窗口一律按「玩家中心过 x1+348」计。
- **平移规则（R6）**：落位只许**向前（+X）平移**，量 ≤160；平移后带电时刻按 +位移/600 补时；超上限则取消本次落缆、改用下一根候选。探针断言：缆中心与 lead 落点偏差 ≤160，且缆左端 x1 > 玩家前缘 px+20（绝不落到身后——ch7 v1 死因）。
- **同台约束**：两桩必须落在同一地表 g 上。从 x1 开始每 32 px 采样一次 `surface_y_at`，跨度内不得变档。跨过档位边界时按上条规则向前平移（≤160）重试，平移后带电时刻补 +位移/600；超上限取消本次。原因是高缆下面要是多出一个 64 的台阶，净空会变成 42−64<0，地形本身就会逼玩家撞缆，所以这种情况在几何上直接禁掉。
- **脚手架避让（R7）**：落位 [x1−40, x1+360] 与任何浮空脚手架（"obstacles" 组成员，`scripts/world/obstacle.gd:31`；floating 档顶 y∈[320,420]，玩家可站）x 区间重叠时，按平移规则前移；移不开就取消。玩家站上脚手架时高缆贴地余量 42 不成立，必须避让而不是校平。针链同规：各针 ±110 范围内不得有脚手架。

**伤害判定**：玩家 AABB（40×60）与缆线段的距离 ≤ 8 就算命中。只在带电期判定。

**读色与预览（R10）**：危险件带电态=**高明度白紫**（芯 `#f0e6ff` + 外辉 `#c9a6ff`）；装饰紫 `#a678e8` **降为低明度 `#6e52a0`**，只用于 Z 标、航标、警示杠。四态预览帧 `art_proposals/storm_ch9/threat_span_states_ch9.png`：松弛灰缆（BELLY 暗缆垂弧）/紧绷灰缆/爬电半程（电花在半程）/带电。

## §2 精英「架线」EliteStringer 放线车

- **机体**：地面车（玩家从旁边路过，不需要维持构图位）。车背是放线绞盘加双管桩炮架，**固定射角不俯仰**（锚桩/喷井家族，`_arm_tracks_pitch` 返回 false）。Muzzle 设在炮架口，挂 ThreatFlash。
- **能力**：单次齐射，射一对跨缆桩，**高/低两型轮流出**（第一发固定高缆，先教「别跳」，第二发低缆，再教「飞或刹」）。数值同 §1。
- **冷却闸（R5）**：上一套跨缆熄灭（或被触溃散）之前不出新的一套——半衰期 2.4 < 一套寿命 2.6，闸压掉叠套（叠套会破坏「高缆后紧跟低缆」的间距保护）。探针断言：同一精英任意时刻 "live_spans" 组内存活 ≤1。
- **教学位**：只预教 BOSS 技能 A。因为这一手最难读（同一个件有两种相反解法），所以要先单件纯净地教一遍。
- **数值**：伤害 10；攻击距离 2200；齐射半衰期 2.4（与八章精英同档，叠套由冷却闸压住）；分数 60。

**躲法实算**（满速跑 vx=600，px 记 0；窗口一律按有效横宽 376 =「中心须在 [x1−28, x1+348] 内保持 h≥48」）：x1=−160+900=740，缆在 [740, 1060]，危险区中心带 [712, 1088]。桩落地 t=0.7；带电从 t=1.6 开始，这时玩家中心在 960，正在缆下。
- 高缆：贴地跑，头顶余量 42 ✓（带电期 1.6–2.6 内中心 1.81 s 过 1088 出缆）。只要按跳就被打（起跳后 0.109 s 撞带）。
- 低缆，飞越（主解，必须按住推进）：h≥48 须覆盖中心带 [712, 1088]。按住推进 0.13 s 到 h=48，此后持续上升 → 最晚起跳 = 中心到 712−78 前，即 t≤1.057。**起跳决策窗 = 落地 0.7 → 1.057，共 0.36 s**（从闪光起算 [1.3, 1.757]，同长）；推进时长约 1.1 s，远小于 2.5 s 的槽 ✓。
- 低缆，刹停（次解）：停点中心 ≤712（身体右缘 732 = 判定带左端）→ 起刹点 ≤612，t≤1.02，**决策窗 0.32 s**。更紧，所以飞越是主解。
- 站桩（vx=0）：缆以玩家为中心，危险区 [px−188, px+188]。低缆要在落地到带电的 0.9 s 里横移 ≥188（起步 0.9 s 能走 440 ✓），或者按住推进 0.13 s 离地到 48 以上 ✓。高缆别跳就行 ✓。
- 倒退（vx=−600）：x1=−560，缆在 [−560, −240]；到 t=1.6 玩家中心约在 −960，已经在缆外 ✓。

## §3 BOSS「引雷」BossConductor 浮空巡线舰

**机体**：外形是门型塔横担，横担两端垂着绝缘子串臂。hover 370，机体 300×180，船底 460。挂件（坐标账见 §0.4，bake_storm_units.py 为唯一准）：
- **Muzzle**：前臂绝缘子串末端放电球，**世界 y=306**（局部 (−68,−64)），是普攻和技能 B 主弧的共用真实源点。按沉锚的账交基类 ArmPivot 俯仰驱动，挂 ThreatFlash。
- **BayPort**：腹舱双桩口（局部 (0,78)），用于技能 A。
- **RodPorts**：背部三孔加 p2 回绕复用（局部 (56,−38)/(80,−34)/(104,−30)），孔数与针数 1:1（同 ch1 MissilePorts 惯例），用于技能 B。
- 航标与举升辉光用低明度装饰紫 `#6e52a0`（R10 降档），独眼条带沿用。

**框架**：继承 PursuitBoss，轮换为 **A → 普攻 → B → 普攻**。后摇分别是 A 1.3 / B 1.4 / 普攻 0.9（`balance_combat.gd:78`），p2 ×0.6（`:79`）。贴脸 700 内压招（`:81`）。水平弹簧和出画不停攻按框架惯例。p2 阈值为半血。血量不加，p2 只加密度。

### 招式 A「跨缆网」

- **预警**：BayPort 上 ThreatFlash 0.6 s，然后按 §1 走灰缆→爬电二段预警。落位/平移/同台/脚手架规则全同 §1（R6/R7）。
- **几何**：
  - p1：一对桩，高/低每轮交替，落位公式同 §1。
  - p2：两段缆，**固定先高后低**。第二段 x1′ = 第一段末端 + 360（1060+360=1420），带电时刻晚 0.6 s（2.2–3.2）。两段都走同台+脚手架约束；放不进就按 R6 向前平移（≤160）并补带电时刻，再不行取消第二段。
- **躲法实算**（p2，满速，px=0；窗口按 376）：
  - 第一段高缆 [740, 1060]，带电 1.6–2.6：贴地跑过 ✓（中心 1.81 s 过出缆线 1088；带电期内身体始终在缆下，头顶余量 42）。
  - 第二段低缆 [1420, 1740]，带电 2.2–3.2：危险区中心带 [1392, 1748]，中心 2.32 s 进带。
  - 解一：**出高缆后（中心过 1088，t≥1.81）立刻按住推进**，0.13 s 后 h≥48 → 最晚起跳 t≤2.32−0.13=2.19，**换层窗 [1.81, 2.19] = 0.38 s** ✓（此时中心 ≥1088 已出高缆判定带，起跳不会撞高缆）。
  - 解二：出高缆后立刻刹车，停点 ≤1392 → 起刹 ≤1292，t≤2.15，停 ~1292，等 3.2 s 熄灭再走 ✓。
  - 读法链就是：**先钻，后飞**。
- **伤害**：10/段，每段至多一次。
- **探针不变式**：
  1. 两桩 `surface_y_at` 相等（同台）。
  2. 高缆对站立静止玩家（不按键）跑满 4 s，掉血 0。
  3. 低缆对站立静止玩家：掉血 = 10，恰好一次。
  4. 低缆对满速 + 在 t≤1.057 起跳并按住推进的玩家：掉血 0（输入脚本：t=0 满速，t=1.0 起跳按住）。
  5. 爬电期与 idle 期对处于缆带内的探针体掉血 0（带电前无伤）。
  6. **同一精英任意时刻 "live_spans" 存活 ≤1（R5 冷却闸）**。
  7. **平移账（R6）**：缆中心与 lead 落点偏差 ≤160；缆左端 > 玩家前缘；平移过的缆带电时刻 = 基准 +位移/600。
  8. **脚手架账（R7）**：任意存活缆的 [x1−40, x1+360] 与 "obstacles" 组 floating 件 x 区间零重叠。
  9. 单威胁源：先排空再戳招（ch7/ch8 探针教训），判定弹种按伤害 10 + live_spans 组计数。

### 招式 B「引雷针链」

**机制（R1 定案）：针高 120，弧带 h∈[112, 128]。纯跳最高点头顶 84.4+60=144.4 会穿过弧带 → 纯跳被弧打；站立头顶 60，弧带底 112，余量 52 → 站缝安全。唯一解法=「贴地刹进缝或停在针列前」，跳就挨弧。与 DrillCharge 的差异账：装药惩罚「留在走廊里」——站/跳都挨爆球；针链惩罚「跳」——站缝免、贴地跑免、跳挨（空中弧判定 8 + 底爆 10 都够得着跳者：跳顶 84.4 < 底爆 90）。**

- **预警与时序（R2，全部从闪光起算 t=0）**：
  1. **RodPorts 出针前挂 ThreatFlash 0.6 s**（真实口位逐孔，t∈[0, 0.6]）。
  2. 逐孔出针（MORTAR_GRAVITY 解算，飞行 0.6 s，梯次 0.1 s）：针1 落地 t=1.2、针2 1.3、针3 1.4（p2 针4 1.5）。
  3. 针尖充能环渐急 1.0 s（第二段预警，无伤）：针1 充能 [1.2, 2.2]。
  4. **放电：针1 在 t=2.2**，此后每 0.25 s（p2 0.2）跳到下一根：p1 放电时刻 2.2 / 2.45 / 2.7；p2 2.2 / 2.4 / 2.6 / 2.8。
- **几何**：
