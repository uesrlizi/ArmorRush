## 1. 能力设计（§4b 门检逐条过）

**招式全家福**：精英「岸炮」预教**跳弹**；BOSS「沉锚」（打捞巡防舰）=
跳弹齐射（技能A）⇄ **深弹涌浪**（技能B）+ 舰炮曳光（普攻直射）。

1. **教学位**：一章只预教最难读的一手=跳弹（弹道有「落点→弹起→再落」三段节奏，
   读法=溅花落点+弹跳弧）；涌浪第一眼读法=海水漫上桥面→往高处/往上跳，现场教。
2. **悬浮账**：BOSS 全悬浮 hover 370（同驳船/哨兵/鮟鱇/断云/赤轮档）：船底 460=
   t2 站立头顶上方 10px，对最高台阶 536 净空 76 ≥70 ✓；艏炮臂枢 (y 局部 −42)
   管长 32 俯角 60° 时管口 ≈456 **不低于船底**；瘫沉 +26 → 486，净空 50 ✓。
   精英=地面炮车（玩家路过它）。
3. **真实枪口律**：跳弹从艏炮管口（俯仰真瞄落点方向）出膛，初速按「落点+时长」
   解算（MORTAR_GRAVITY 真弹道），落点=玩家当时脚下路面（抛体落点自身贴地，无需
   直瞄校平）；深弹从艉舱口（BayPort）向艉侧抛出落海；曳光从艏炮管口直瞄出膛。
   **全游戏首个弹跳弹道**：落地按 `surface_y_at` 判接触，接触即反弹（apex 固定、
   水平速度按跳序衰减）；撞台阶立面（埋深 > 40）=撞墙当场起爆，零穿模。
4. **相对速度**：跳弹落点=玩家**当时位置**（无 lead——「炮弹落你脚下再弹起来追」
   就是机制：停=吃落点；顺弹向跑=被下一跳追咬；**跳过弹体=免**；逆向冲过=免）。
   涌浪=固定绝对高度带（不管地面、零地形跟随，同珊瑚潮账）：低处=吃/高处=免/
   升空=免。追踪语汇零涉及。
5. **数值命名**：`ELITE_SHORE_*` / `ANCHOR_*` / `SKIP_SHELL_*` / `DEPTH_CHARGE_*` /
   `SEA_SURGE_*`，禁章号。
6. **读法/量级**：跳弹 44×16 暗壳+白热曳光带（亮底靠暗壳剪影读；每次触地喷
   **白沫溅花** 48px 级=落点读出件，fx 量级对标 fx_smoke 档）；深弹 18×26 暗鼓
   +橙灯；涌浪=全屏宽半透青绿水体 + 白沫浪冠（3200×400 条带钉镜头），落海
   白沫水花+海面闷爆青白晕=「水要来了」二段预警。

**贴地跟随禁令复核**（2026-10-23 用户定案：危险件要么静止落点要么固定高度带）：
跳弹=**真弹道抛体**（每一跳都是解析抛物线，接触点离散判定，台阶立面=撞墙起爆），
不是沿地表滑行的跟随件；涌浪=固定绝对高度带（珊瑚潮同类，合法）。

**惩罚账**（BOSS 版，落点 x0=玩家当时位）：
- 站桩：落点 x0 即弹体接触带中心 → **吃**（接触=起爆 10）；
- 顺弹向全速跑 600：首段 0.55+首跳 0.424=0.97s 位移 584，第二跳落点 x0−509
  ±170=[−679,−339] → 跑者在 −584 **带内被追咬**（跳弹"追着咬"的读法成立）；
- **跳过弹体=免**：纯跳脚底 +67 > 弹体 r22+判定余量，滞空 ~0.74s 覆盖弹过身窗口
  （弹在跳弧末端低于 78 的时段 ≈0.13s）；逆向冲过弹体中段=免（弹在头顶 90−30=60 >48）。
- 全链时长：预警 0.5 → 首段 0.55 → 三跳 1.27 → 爆，≈2.3s；BOSS 后摇 1.3。
