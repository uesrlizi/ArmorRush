# 第十章「硫焰地热田」威胁设计：精英「窜井」与 BOSS「井口」

本章母题：**「井压在看，火焰走直线」**——井口冒的蓝火在出手前把「井在哪、要喷哪」摆给玩家看，玩家的工作是提前换层。地面上的事归技能，天上的事归普攻。

- 精英「窜井」EliteFountain 井口封堵车：在玩家前路钻开**单口双喷**硫焰井口，预教本章核心件「硫焰井口」——**喷 0.45s / 息 0.75s / 再喷 0.45s，第一眼读法=看第一喷、息窗里穿，否则吃第二喷**。
- BOSS「井口」BossWellhead 井场管线母舰：技能 A「井压线」（三/四口纵队）+ 普攻「硫焰扫掠」+ 技能 B「硫云爆燃」（全游戏首个横向推火锋）轮换。

数值全部只进 `scripts/core/balance/balance_world_10.gd` 的 const，命名按机体（`ELITE_FOUNTAIN_*` / `WELLHEAD_*` / `VENT_*` / `SULFUR_CLOUD_*` / `FLARE_SWEEP_*`），不用章号（worlds.md §4b 门检 5）。

## §1 本章核心危险件「硫焰井口」SulfurVent（新弹种）

**构成**：井口底座（静止落点件，DrillCharge/锚桩同族）钻定当地地表，口上周期喷蓝焰柱。**焰是竖直静止墙，不是弹**。

**时序（R3：全部用绝对时间，从发射方 ThreatFlash 亮起 t=0 起算；单口定值）**：闪光 [0, 0.6] → 钻头飞行 0.7 → **落位 1.3** → 钻入到 1.7 → **亮井 1.7 起**（读出期，无伤）：
1. **亮井层**：口内蓝焰从微光渐急到全亮——「这口井开着」的常亮读出层，无伤。
2. **喷发**：**单口首喷 = 1.7+0.6 = 2.3**，喷 0.45 / 息 0.75（周期 1.2），脉冲在相对首喷 0 / 1.2 / 2.4，**BOSS 纵队井每口固定 3 喷**，**熄灭时刻 = 首喷+2.85**（单口 2.3 起=5.15；寿命按每口自己的末喷熄灭算，不设统一全寿命值）；**精英井（R8）每口固定 2 喷**：喷 [2.3,2.75] → 息 [2.75,3.5] → 喷 [3.5,3.95]，熄灭 = 首喷+1.65 = 3.95。
3. **纵队（§3 A）**：第 k 口的首喷 = 2.3+0.6k（k=0,1,2,3 → 2.3/2.9/3.5/4.1），**靠「该口亮井期按 k 延长 0.6k」实现，不靠出膛梯次**（钻头出膛梯次 0.15 只是出膛节奏的视觉连续）。

**判定几何**：
- 井筒宽 64（判定半宽 32 + 玩家半宽 20 = **有效半宽 52**）。
- 焰柱高 **220**：纯跳脚底最高 83.4 = 高度的 38% → **跳≠过**（SaltGeyser「柱是墙」同账）；有效宽 104 << 刹停+起步可横移量 → **钻缝/等息=过**。
- 一次喷发至多结算一次，伤 10。亮井期（含渐急的预喷微光）无伤。
- **无 ThreatFlash**——预警是井口自身的「亮井渐急」渐亮层（同 SlagPool 蓄热语汇：亮=待喷，不是反馈）；钻头飞行本身按真实枪口律从 DrillPort 出膛，可读。落地件不挂枪口闪光是该家族现行惯例（DrillCharge 红灯渐急、SaltGeyser 环纹均无 ThreatFlash）。

**亮井闪烁频率（R11，多口同亮时的先后读出规则）**：亮井层按 `f = min(1/剩余首喷时间, 4) Hz` 闪烁（剩余首喷时间 = 该口首喷时刻 − 当前 t）。判据：剩余时间 >0.25s 时，同一时刻剩余时间更少的井 f **严格更大**（1/x 在 x>0.25 上严格递减）；纵队相邻口首喷相差 0.6s，任一时刻至多一口落入封顶区（剩余 ≤0.25s），不会两口同时封顶。首喷之后的息窗沿用同一公式对「剩余到下一喷时间」计。绿波窗保持现值 [2.75, 3.1]。

**落位档位边界避让（R10，§2/§3 共用）**：井落点 xv 距任一地块边界 x=320·n 小于 52（=有效半宽）时，依次试 xv+96、xv−96；仍不合格（含脚手架 ±104 重叠）则**取消该口**。A 纵队被取消的口留空，其余口保持原 k 与首喷 2.3+0.6k，不重排。

**读法**：口宽 64 + 喷息 0.75 = **闸是宽门，钻它就是等它息**；焰高 220 = 别想跳。蓝白焰在赭橄榄天/玄武黑地上都是亮层（提案 §3 色相账）。

## §2 精英「窜井」EliteFountain 井口封堵车

- **机体**：地面封堵工程车（玩家路过，不需构图位）。车尾钻机架**固定射角不俯仰**（`_arm_tracks_pitch` false），钻杆从架口垂发。单井套件挂在 DrillPort：**出钻前 DrillPort 挂 ThreatFlash 0.6s（warn() 同拍警告音，R6，与 BOSS 技能 A 同规格）**→ 钻头出膛（飞行可读）→ 井口自身亮井层接棒；井口本身不挂 ThreatFlash，用亮井渐急层做预警（亮井期无伤，不设首喷前判伤）。
- **能力（R8：单口、双喷节拍，教「等息穿」）**：单发钻头落**玩家前方一路** `xv = px + clamp(vx·2.4, 240, 1440)`——满速玩家抵达井位（t=2.4）恰处第一喷 [2.3,2.75]；落点贴当地 g、零跟随。单口固定 2 喷：**第一喷 0.45s → 息 0.75s → 第二喷 0.45s**，3.95 熄灭。
- **落位避让**：档位边界避让按 §1 R10（距 320·n <52 → 试 +96、−96 → 仍不合格取消本口）；脚手架 ±104 内不得有 floating obstacles，同一 +96/−96 序列重试。
- **冷却闸**：上一口井熄灭（喷完 2 次）前不出新套（"sulfur_vents" 组同主存活 ≤1）。
- **教学位**：预教 BOSS 技能 A 的单口节拍读法（「看第一喷、息窗里穿」），A 纵队是同一读法的串联。
- **数值**：伤 10；攻击距离 2200；齐射半衰期 2.4；分数 60。

**差异账（对 ch8 SaltGeyser / EliteGusher）**：喷井的间歇泉是**一次性汽柱**（0.7s mark → 0.55s 柱 → 灭），读法是「**离开，或等它喷完**」——柱灭了就没了，没有节拍可读。窜井是**有节拍的闸**：第一喷是演示，**0.75s 息窗是给你穿的门**，错过息窗就撞第二喷。新读法=「**看第一喷，在 0.75s 息窗内穿过，否则吃第二喷**」——罚的不是「站在落点」，而是「看到喷了还犹豫」。（同为固定射角钻车家族，此处只是机体同族，读法不同族。）

**躲法实算**（`threat_calc_ch10.py` elite_r8_cases 实跑；井心 xv=px+1440；井判据=玩家中心距井心 ≤52 且脚底 h<220）：

## §3 BOSS「井口」BossWellhead 井场管线母舰

**机体**：外形=一座飞着的井场平台：艏部一根井口喷嘴（NozzlePort），腹下钻杆井（DrillPort），艉部排烟囱（VentPort）；墨酒红族色板+硫焰蓝喷焰（提案 §4）；**甲板长管改为无发光口的井架吊杆（R12）**——全机只有 Nozzle/Drill/Vent 三个出手口带发光，吊杆是纯结构件，不得出现任何像枪口的蓝色发光端。hover 370。继承 PursuitBoss，轮换 **A → 普攻 → B → 普攻**；后摇 A 1.4 / B 1.4 / 普攻 0.9（BOSS_DIRECT_RECOVER，`balance_combat.gd:78`），p2 ×0.6；贴脸 700 压招；水平弹簧/出画不停攻按框架。血量不加，p2 只加密度。

### 招式 A「井压线」

- **预警**：DrillPort ThreatFlash 0.6s（出钻头前，warn() 同拍警告音）→ 钻头逐口出膛（梯次 0.15，视觉节奏）→ 各井自身亮井层接棒（§1）；**第 k 口首喷 = 2.3+0.6k 由该口亮井期按 k 延长 0.6k 实现（R3），不靠出膛梯次**。
- **几何**：p1 三口纵队 `xk = xv + k·360`（xv 公式同 §2，clamp(vx·2.4, 240, 1440)），首喷 2.3/2.9/3.5；p2 四口（+2520，首喷 4.1）。各口贴当地 g、零跟随、固定 3 喷、熄灭 = 各自首喷+2.85；一次喷发至多一次。**档位边界避让（R10）**：每口独立按 §1 规则——距 320·n <52 → 试 +96、−96 → 仍不合格（含脚手架 ±104）取消该口；**被取消的口留空，其余口保持原 k 与首喷 2.3+0.6k，不重排**。多口同亮的先后读出按 §1 R11 闪烁频率。

### 招式 B「硫云爆燃」（全游戏首个横向推火锋）
