## 1. 三层背景分工

**far 远景条（视差 0.9）：用破火山口壁做成片主体块**
- 两排火山口壁用整数周期的正弦折线画：后排每 1024 一个周期，前排每 1024 两个周期，接缝两侧取值相同，平铺不断。折线步长较粗，形成棱面。后排壁顶约在世界 310..380，前排约在 390..440，成片顶到规约要求的世界 250..430 区间。
- 前排壁顶上坡段有一道硫黄色淡受光缘。壁面散布硫黄结壳斑，壁脚嵌两处喷气孔小蓝焰。
- 硫烟柱从壁后升起，画法是一串径向软光晕烟团，越往上越大、越淡，并略向右飘；烟柱根部被前排壁盖住，读作从火山口里冒出来。
- 地平线一带铺一层硫雾暖辉（径向软光）。高空烟幕只画低对比横条。
- 底雾只压脚，100px 以内，不透明度 ≤0.4。条带里不放唯一地标。

**mid 中景条（视差 0.55）：地热电站挂件，四段构图各不相同**
1. 汽水分离塔：本章最高的中景件，罐顶在世界约 394，和前章最高件同档。罐身有箍带，旁边立梯架；出汽管接到支架上，罐顶有放空汽。
2. 井口阀树加 Ω 形伸缩弯管：井口顶上漏着一簇硫焰，蓝火是本章最显眼的点缀。横管由四根管托撑着，Ω 弯顶上挂一盏航标蓝灯。
3. 硫黄堆加输送斜槽：一座亮硫黄锥堆，斜槽下端搭在堆顶，上端有支柱落地。
4. 喷气孔围栏加警示牌：孔口冒烟柱和蓝焰，周围一圈围栏桩；警示牌牌面有亮缘描边，中间一道硫焰蓝警示杠。
- 落地件的脚全部在画布 488..500。图①和图②里逐件压在 664 红线上，没有悬空。管线两端都接在实物上（罐、支架、井口、管托）。

**地形性格：玄武岩硬地加硫黄壳（ground_v2 画法，主题键 `p10_sulfur`，借用盐壳分支的画法）**
- 走道带：冷灰黑玄武岩，带面有细裂纹，零星硫黄结壳斑和结晶点。顶缘是一道硫黄淡亮线。
- 立面：深玄武，断面上有淡硫黄竖纹。
- 档位节奏用标准山体读法：两侧低平地放分离塔、喷气孔围栏和警示桩；中段高台放井口阀树、Ω 管和硫黄堆；过渡台放独层大件井架。整条地形读作「管线检修道」：高台是井场平台，低平地是管廊通道。

**撞族自查**：前九套依次是锈橙暖褐、冷绿、冷蓝灰雪、暗红夜配亮钢蓝、金霞配紫罗兰、白热赤红、青绿海光、杏金绯粉、青灰绿配雷光紫。本章是黄绿偏的赭橄榄天、中性冷灰黑地、硫焰蓝点缀。
- 最接近的是五章金霞和八章杏金。金霞和杏金偏橙金（暖红侧），本章天色偏黄绿（橄榄侧），而且饱和度更低、带烟灰感，读作「硫烟」而不是「霞光」。从图②三行并排看，和八章明显分开。
- 二章冷绿是偏蓝的绿，本章是偏黄的橄榄，不同族。
- 这条撞族边界交给评审确认。

## 3. 章信号色

**硫焰蓝 `#48b4ff`**（浅芯 `#c8ecff`）：用在井口和喷气孔的燃烧硫焰、航标灯、警示杠、敌方推进焰和举升辉光。
- 题材依据：硫黄燃烧的火焰本来就是蓝色。蓝火出现在赭黄天上，对比强，一眼就是本章的记号。
- 它和独眼红 `#ff4640`、共享黄弹 `#ffee58` 色相错开。
- 有一处要注意：地面硫黄壳是黄色系，和共享黄弹同族。所以结壳全部压成低饱和赭黄（`#c8b048`），只做低不透明度的小斑，不放大面积高亮黄。实装时要拿实机截图核一次黄弹在走道带上的可读性。

## 4. 敌营配色（墨酒红族，近黑=敌，不反转）

| 阶 | hex |
| --- | --- |
| LIGHT | `#6a4456` |
| BODY | `#4a2a3a` |
| BELLY | `#321c28` |
| GAP | `#20121a` |
| 独眼 | `#ff4640` |
| 点缀 | 硫焰蓝 `#48b4ff`（推进焰、举升辉光） |

- 本章是中调背景，不是暗场章，所以按「近黑=敌」处理，不反转；不用奶油白，也不用低对比浅色。
- 墨酒红在赭橄榄天上接近补色，BOSS 和无人机悬在天里靠色相就能跳出来（见图③）。
- 地面单位踩在玄武冷灰黑走道带上，靠色相分开：酒红偏暖，走道带是中性冷灰。BODY 和走道带的明度接近，所以靠 LIGHT 肩部受光条和独眼红立住轮廓。评审时请重点看图③的地面四个单位。
- 和六章赤红暗棕 `#6e3424` 的区分：那是偏橙的红棕，本章偏紫红（酒红），而且明度更暗。
- HUD 用深字（天色中调偏亮，实装时以实机截图为准）。

## 5. 独层大件：倾斜巨型地热井架（建议名 `env_sulfur_derrick`，独层宽 tile，同屏只出现一份）

- 一座钻井井架。地热井失控喷发后，井架被冲歪了，斜着指向天空。钻台底座坐在台面上，司钻房还坐在底座上；井口一直在烧蓝色硫焰，架顶天车还在放空冒烟。
- 尺度：主视景里井架高约 260px（半比例），是中景分离塔的 2 倍左右，读得出「巨」。
- 辨识轮廓：一根斜长的桁格塔身，加顶端的天车方块和一缕烟。
- 落位按独层规矩：tile 宽大于 2400，tex_x 放在防回绕安全带内，画在不透明远条之后、MidStrip 之前。条带里不再放第二个大件。
- 主视景里井架整座坐在过渡台台面上（x 720..910，脚线 300，等于台顶），塔身斜挑到右侧平地上空。已经逐件对过档位区账，没有埋件。

## 6. 本章普攻换形方向

**方向：「硫焰扫掠」**。BOSS 艏部的井口喷嘴在出手瞬间锁定一个起始角，然后沿固定弧度扫一次，喷出一串蓝色硫焰团。扫的路线在出手时就定了，之后不跟踪玩家。

**和主题相配的理由**：
- 本章的母题是「井口在烧蓝火」。BOSS 本身就是一座会飞的井场，普攻就是把井口的火喷出来。喷嘴是真实存在的枪口，符合真实枪口律。
- 它属于「出手锁定的一次性形态」这一家族（ch2 排炮重弹、ch4 钓灯爆闪、ch6 斗轮抛石、ch8 融盐重弹）。和前四家的形态区分：前四家分别是慢重弹（点）、径向齐放（面）、抛体落点（落点簇）、单发点放（点）。这一家是一次固定方向的扫掠，玩家看的是火焰扫过的那条弧，解法是读清扫向，然后换层或者让开。
- 可读性：蓝白火焰团在赭橄榄天上是补色对比，在玄武黑地上是亮色对比，两种背景下都读得出。
